4) Explain it: 
The program first asks the user to enter their age and checks that it is a whole number that is 0 or greater. If the age is invalid, it prints “Invalid age” and stops without asking any more questions. If the age is valid, it asks whether the ticket is for a matinee and calculates the ticket price based on the person’s age. If it is a matinee, the program subtracts $3 from the price but never lets it go below $0. Finally, it prints the ticket price with exactly two decimal places.
